# Project Master File — «Оазис»

## Текущий статус
**Этап 0.2.0 — адаптивная стартовая сцена.** Разметка учитывает размер окна, портретную и альбомную ориентацию, безопасные отступы и мобильную нижнюю панель. Это прототип адаптации, а не полное тестирование на физических устройствах.

## Готово в этом архиве
- Phaser-сцена с названием, ресурсами, фазой дня/ночи.
- Изометрическая тестовая сетка и условный колодец.
- Относительное масштабирование UI и карты при изменении размеров окна.
- Различная компоновка для портретной и альбомной ориентации.
- Базовое сохранение в localStorage.

## Не готово
- Игровые действия, посадка и сбор урожая.
- Реальные иллюстрированные ассеты.
- Арыки и механика орошения.
- Животноводческие здания и производство.
- Экономика, рынок, улучшения, садака/баракат.
- Родительский контроль и таймер молитв.
- Полная офлайн-симуляция.
- Проверка на реальных устройствах iOS/Android и в Telegram Mini App.

## Схема localStorage
Ключ `oasis_save_v1`: `version`, `lastSavedAt`, `player.gender`, `resources`, `inventory`, `farm`, `buildings`, `animals`, `tools`, `barakat.multiplier`, `sadaka.hiddenTotal`, `settings`, `parentalControl`, `prayerTimer`, `decorations`.
