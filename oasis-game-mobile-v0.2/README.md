# Оазис — адаптивный стартовый прототип v0.2.0

1. Распакуйте архив.
2. Откройте `index.html` двойным щелчком. Для загрузки Phaser.js с CDN требуется интернет.
3. Проверьте сцену в широком окне, затем измените размер окна. В портретном окне интерфейс должен перестроиться.

Это ещё не законченная игра. Карта и колодец нарисованы геометрическими фигурами; игровые действия будут добавлены следующими этапами.
