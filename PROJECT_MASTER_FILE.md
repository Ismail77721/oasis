# PROJECT_MASTER_FILE.md — Оазис
Версия: **0.3.0**. Этап: механики прежде тяжёлой графики.

## Реализовано
- Логическая матрица 10×10 с сохранением клеток.
- Адаптивное изометрическое поле.
- Выбор арбуза/клевера, посадка, рост по времени, полив, сбор.
- Режим арыков: построить за 4 монеты, разобрать с возвратом 2.
- Отображение и сохранение арыков.
- Колодец: касание центральной зоны обменивает 2 монеты на до 3 воды.
- Номер версии вверху справа.
- localStorage и миграция состояния.
- Скрытый учёт садака 2,5% при сборе урожая (временная логика).

## Известные ограничения
- Арыки пока не рассчитывают связь с колодцем и не проводят воду автоматически.
- Видна только часть 10×10 поля.
- Ночь меняет фон и подпись, но пока не замедляет рост.
- Баланс предварительный.
- Архив не запускался на физическом смартфоне в этой среде: после загрузки проверь на GitHub Pages.

## Следующие этапы
1. Реальная сеть арыков, связь с колодцем и доступность воды по клеткам.
2. Замедление роста ночью и офлайн-прогресс.
3. Базар, расширение, полный цикл экономики.
4. Закрытый шатёр овец и загон верблюдов, производство без изображения животных.
5. Садака 2,5%/5%, баракат, инструменты по 5 уровней.
6. Обучение текстом, родительский PIN/лимит, таймер молитв.
7. Природные/механические звуки без музыки.
8. Финальная графика и кросс-девайс тесты.

## Управление
- Посадка: пустая клетка — посадить; растущая культура — полить; зрелая — собрать.
- Арык: пустая клетка — построить; повторное касание — разобрать.
- Кнопки «Арбуз» и «Клевер» выбирают культуру.
- Колодец находится в центре поля; нажми по нему, чтобы купить воду.

## Временный баланс
Старт: 100 монет, 10 воды, 20 энергии. Арбуз: стоимость 5, рост 45 сек., урожай 3, продажная цена 4/ед. Клевер: стоимость 3, рост 25 сек., урожай 2, цена 2/ед. Полив: 1 вода, ускорение около 20%. Арык: построить 4, разбор 2. Колодец: 2 монеты за до 3 воды.

## Сохранение
localStorage key: `oasis_save_v1`. Поля: `version`, `createdAt`, `lastSavedAt`, `coins`, `energy`, `water`, `selectedCrop`, `tool`, `inventory`, `hiddenSadaqaTotal`, `barakatLevel`, `tiles`. Клетка: `crop`, `plantedAt`, `watered`, `canal`.

## Ограничения GDD
Не изображать людей, животных, лица, силуэты или тела существ. Животные только внутри закрытых строений. Наставники — текст/стрелки. Музыки нет. Сервер и внешняя база данных не используются.
