# Оазис v0.3.0
1. Распакуй архив.
2. Загрузи содержимое папки `oasis-game-v0.3.0` в прежнюю папку проекта GitHub, заменив файлы.
3. Сохрани прежний URL и обнови страницу принудительно.
4. Проверь: версия v0.3.0, выбор арбуза/клевера, посадка/полив/сбор, режим арыков, сохранение после перезагрузки.

Phaser загружается с CDN, поэтому нужен интернет. Сохранение хранится в localStorage конкретного браузера. Арыки пока визуально строятся и сохраняются, но не проводят воду автоматически. Архив не проверен на физическом устройстве в этой среде.
